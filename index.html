Analysis of legacy Windows Batch & VBScript mechanics with mitigation strategies.

⚠️ Educational Notice: All scripts in this laboratory are provided strictly for security analysis, signature auditing, and operating system mechanism research.

Shutdown PC Batch Script

Medium Risk

Triggers an automatic system shutdown sequence after a 10-second timer using the native Windows shutdown utility.

shutdown -s -t 10
🛡️ Defensive Remedy: Run shutdown -a in command prompt to immediately abort pending shutdowns.

CapsLock Loop VBScript

Medium Risk

Injects virtual keystrokes via WScript.Shell SendKeys to repeatedly toggle the CapsLock indicator.

Set wshShell = wscript.CreateObject("WScript.Shell")
wshShell.sendkeys "{CAPSLOCK}"
🛡️ Defensive Remedy: Terminate the script engine process via taskkill /f /im wscript.exe.

System32 Removal Target

High Risk

Attempts recursive deletion of critical system binaries (System32).

del /f /s /q c:\windows\system32
🛡️ Defensive Remedy: Windows UAC, System File Protection (SFC), and TrustedInstaller permissions block unprivileged deletion.

CMD Fork Spawner

Medium Risk

Recursively spawns new command prompt instances, consuming CPU and memory resources.

:top
start cmd
goto top
🛡️ Defensive Remedy: Kill command prompt processes using taskkill /f /im cmd.exe or Process Explorer.
